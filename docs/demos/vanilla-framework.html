From bare metal to workloads in three steps

The same commands work on a Raspberry Pi, a factory gateway, or a rack of servers.

Install

Lattice ships as a snap, so installation is identical on Ubuntu Server, Core, and Desktop. Dependencies resolve themselves.

$ sudo snap install lattice --classic

Configure

Answer four questions or hand it a preseed file. Networking, storage, and ingress get sensible defaults you can change later.

$ lattice init --preseed factory.yaml
# storage: ceph · ingress: traefik · dns: 10.0.0.2

Scale

Joining a node prints a token. Run it on the new machine and the cluster absorbs it — no control-plane surgery.

$ lattice join --token 9f2c-41ad --role worker

Note: Ubuntu 24.04.3 LTS is the recommended host. 22.04 LTS is supported through 2032.
