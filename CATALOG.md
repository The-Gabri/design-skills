# Design Skills Catalog — 70 skills

Target repo: `design-skills` (public, MIT). Every skill: Agent Skills open format
(`SKILL.md` + YAML frontmatter `name`/`description`) so it works in
Claude Code, Codex, Cursor, Windsurf, Copilot, and any agent that reads the
open skills format. All content in English. Each skill ships a `demo.html`
single-file page that demonstrates the style.
