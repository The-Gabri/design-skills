field manual · excerpt

Read before you run.

rule 01 // patience

Q — How long should recon run?

Ninety seconds minimum. The grid lies to anyone in a hurry — patrol patterns only reveal themselves to runners who watch a full rotation before moving.

rule 02 // noise

Q — What trips the ICE fastest?

Retries. One clean breach attempt beats ten noisy ones. If the drill scores under 95, you are not ready — run it again in the sim, not on the target.

rule 03 // exit

Q — When do I burn the route?

Always. Every exfil route is single-use. Ghostlink burns it automatically and verifies the ash — a route you reuse is a trail you left.

rule 04 // crew

Q — Can the corps trace Ghostlink itself?

The console runs local, signs nothing, phones home never. There is no account, no cloud, no log with your name on it. That is the whole point.
